## 2. FUNCTIONAL & INTERACTION BUGS DISCOVERED

### 🚨 Critical Bug 1: Backend Crash on Custom Complaint ID (`CastError`)
- **Location**: `server/server.js` (lines 21 & 22)
- **Problem**: When requesting `GET /api/complaints/CMP-2026-00005`, the route executes:
  ```js
  Complaint.findOne({ $or: [{ _id: req.params.id }, { complaintId: req.params.id }] })
  ```
  Because `CMP-2026-00005` is not a 24-character hexadecimal string, Mongoose throws an unhandled:
  `CastError: Cast to ObjectId failed for value "CMP-2026-00005" at path "_id"`
  causing a `500 Internal Server Error`.
- **Fix**: Check `mongoose.Types.ObjectId.isValid(id)` before querying by `_id`:
  ```js
  app.get('/api/complaints/:id', auth(), async (req, res) => {
    try {
      const isOid = mongoose.Types.ObjectId.isValid(req.params.id);
      const query = isOid 
        ? { $or: [{ _id: req.params.id }, { complaintId: req.params.id }] } 
        : { complaintId: req.params.id };
      const c = await Complaint.findOne(query).populate('submittedBy assignedTo', 'name email department');
      if (!c) return res.status(404).json({ message: 'Complaint not found' });
      res.json(c);
    } catch (e) {
      res.status(500).json({ message: e.message });
    }
  });
  ```

### 🚨 Critical Bug 2: Missing Navigation Links on Table Rows (`RequestTable`)
- **Location**: `client/src/main.jsx` (line 17: `RequestTable` and line 21: `AdminComplaints`)
- **Problem**: Table rows render static text. Users cannot click into a complaint to view its description, timeline, or attachments.
- **Fix**: Wrap the reference number and title in `<Link to={`/complaints/${c._id}`}>`:
  ```jsx
  <td>
    <Link to={`/complaints/${c._id}`} style={{ textDecoration: 'none', color: '#1e3a8a', fontWeight: 700 }}>
      {c.complaintId}
    </Link>
  </td>
  <td>
    <Link to={`/complaints/${c._id}`} style={{ textDecoration: 'none', color: '#111827' }}>
      <b>{c.title}</b>
    </Link>
    <small>{c.category} · {c.department}</small>
  </td>
  ```

## 3. UI/UX LAYOUT & RESPONSIVENESS DEFECTS (BROWSER AUDIT)

### 🚨 Layout Defect 1: Global `nav` Collision & Floating Pseudo-Element
- **Selectors**: `nav`, `nav::before`, `.saas aside`, `.side-nav`, `.landing-nav nav`
- **Source Files**: `responsive.css` (lines 34–38), `style.css` (line 1)
- **Defect**:
  - `responsive.css:34` defines a generic `nav` selector with `position: fixed; inset: 0 auto 0 0; width: 248px;`. This forces `<nav className="side-nav">` inside `<aside>` to break out and cover the brand header and workspace banner.
  - `nav::before` injects a duplicate floating `"ResolveX"` header on top of the sidebar.
  - On mobile screens (≤767px), `style.css:1` pins `nav` to `bottom: 0`, creating an unstyled phantom bottom navigation bar.
- **Fix**: Remove all global `nav` and `nav::before` selectors. Scope navigation styles exclusively to `.side-nav` and `.landing-nav nav`.

### 🚨 Layout Defect 3: Tablet (768px–1024px) Grid Blowout & Horizontal Scrolling
- **Selectors**: `.dashboard-grid`, `.metric-grid`, `.workspace-main`, `.page`
- **Source Files**: `responsive.css` (line 54)
- **Defect**:
  - On a 1024px tablet, available content width is `684px`.
  - `.dashboard-grid` (`minmax(280px, .8fr)`) and `.metric-grid` force a minimum width of `781.13px`, blowing page `scrollWidth` out to **1121px** and causing an unwanted horizontal scrollbar.
  - At 768px, the request table is squished down to **196px** while containing a 550px table.
- **Fix**:
  ```css
  .metric-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 16px;
  }
  @media (max-width: 1100px) {
    .dashboard-grid {
      grid-template-columns: 1fr;
    }
  }
  ```
